# Расписание (Kivy + Android-виджет)

- `main.py` — приложение (вкладки «Расписание», «Экспорт», «Справка»)
- `sample_data.py`, `generate_excel.py` — тестовый Excel (`python generate_excel.py`)
- `java/`, `res/`, `extra_manifest_application.xml` — Android-виджет
- `buildozer.spec`, `.github/workflows/build.yml` — сборка APK на GitHub

Запуск на ПК: `pip install -r requirements.txt && python main.py`
